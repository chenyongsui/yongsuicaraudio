# Prompt：生成云函数代码

## 任务
根据数据库设计和管理功能需求，生成完整的腾讯云函数代码。云函数不一定要按照文档里面的严格控制，如果有更合适的，codebuddy可以自由发挥。

## 云函数列表

### 用户端云函数
| 函数名 | 功能 |
|--------|------|
| login | 用户登录/注册 |
| getProducts | 获取商品列表（支持分类、分页、排序） |
| getProductDetail | 获取商品详情 |
| getCategories | 获取分类列表 |
| getMarquee | 获取滚动公告 |
| getBanners | 获取轮播图 |
| createOrder | 创建订单 |
| getOrders | 获取用户订单列表 |
| getOrderDetail | 订单详情 |
| cancelOrder | 取消订单 |
| rechargePoints | 积分充值（创建支付参数） |
| payCallback | 支付成功后积分到账回调 |
| getRechargeActivities | 获取充值活动列表 |
| getUserPointsRecords | 积分明细 |
| getCoupons | 获取可用优惠券 |
| receiveCoupon | 领取优惠券 |

### 管理端云函数
| 函数名 | 功能 |
|--------|------|
| adminLogin | 管理员登录验证 |
| adminCheckAuth | 验证管理员身份 |
| adminGetDashboard | 获取首页统计数据 |
| adminGetUsers | 用户列表 |
| adminUpdateUserPoints | 调整用户积分 |
| adminGetProducts | 商品列表 |
| adminSaveProduct | 保存商品 |
| adminDeleteProduct | 删除商品 |
| adminGetCategories | 分类列表 |
| adminSaveCategory | 保存分类 |
| adminGetBanners | 轮播图列表 |
| adminSaveBanner | 保存轮播图 |
| adminDeleteBanner | 删除轮播图 |
| adminGetCoupons | 优惠券列表 |
| adminCreateCoupon | 创建优惠券 |
| adminSendCoupon | 发放优惠券 |
| adminGetRechargeActivities | 充值活动列表 |
| adminSaveRechargeActivity | 保存充值活动 |
| adminDeleteRechargeActivity | 删除充值活动 |
| adminGetMarquee | 获取公告 |
| adminSaveMarquee | 保存公告 |
| sendPushMessage | 发送模板消息 |
