# Prompt：生成后台管理页面代码

## 任务
根据管理员配置和核心功能，生成完整的后台管理页面代码（小程序内嵌形式）。

## 页面清单

| 页面 | 路径 | 核心功能 |
|------|------|----------|
| 登录页 | pages/admin/login | 账号密码登录、白名单验证 |
| 首页 | pages/admin/index | 数据统计卡片、功能菜单入口 |
| 商品管理 | pages/admin/goods | 列表、添加、编辑、删除、上下架 |
| 分类管理 | pages/admin/categories | **五大分类编辑**（名称、排序、启用） |
| 用户管理 | pages/admin/users | 列表、搜索、积分调整 |
| 轮播图管理 | pages/admin/banners | 列表、上传、排序、启用/禁用 |
| 优惠券管理 | pages/admin/coupons | 创建、列表、发放 |
| 积分活动管理 | pages/admin/recharge | 充值活动配置（充多少送多少） |
| 公告管理 | pages/admin/marquee | **滚动公告编辑（红色字体）** |
| 营销推送 | pages/admin/push | 消息发送 |

## 功能要求

### 通用要求
1. 每个页面 `onLoad` 时检查登录态，无权限跳转登录页
2. 列表页面支持分页加载
3. 表单页面包含完整的校验
4. 删除操作需要二次确认

### 商品管理
- 支持按分类筛选
- 支持图片上传到云存储
- 支持富文本描述

### 分类管理
- 只能编辑五大分类，不可删除
- 可修改名称、排序、启用状态
- 可上传分类图标

### 公告管理
- 编辑滚动公告文字
- **颜色选择器**（默认红色 #ff0000）
- 背景颜色选择器
- 滚动速度滑动条
- 实时预览效果

### 营销推送
- 选择推送对象（全部用户/指定用户）
- 编辑消息标题和内容
- 调用云函数发送模板消息

## UI 样式要求
- 使用 WeUI 组件库风格
- 后台采用卡片式布局
- 表单使用 `form` 组件，支持 `bindsubmit`
- 列表使用 `scroll-view` 实现滚动加载

## 输出格式
为每个后台页面生成完整的代码文件：
