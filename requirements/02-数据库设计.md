# 数据库设计

## 集合（表）结构

### 1. users（用户表）
| 字段名 | 类型 | 描述 |
|--------|------|------|
| _id | string | 自动生成ID |
| openId | string | 微信OpenID（唯一） |
| nickName | string | 用户昵称 |
| avatarUrl | string | 头像URL |
| phone | string | 手机号（可选） |
| points | number | 当前可用积分 |
| totalPoints | number | 累计获得积分 |
| usedPoints | number | 已使用积分 |
| role | string | `user` 或 `admin` |
| status | string | `active` / `disabled` |
| createTime | date | 注册时间 |
| lastLoginTime | date | 最近登录时间 |

### 2. categories（分类表）
| 字段名 | 类型 | 描述 |
|--------|------|------|
| _id | string | |
| name | string | 分类名称（如“汽车脚垫”） |
| key | string | 英文标识（用于前端跳转） |
| icon | string | 图标URL |
| sortOrder | number | 排序（1-5） |
| status | bool | 是否启用 |
| createTime | date | |
